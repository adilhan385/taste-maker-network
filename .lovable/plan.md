# Исправление отправки кода на почту при регистрации

## Что выяснено

- Домен `notify.chefcook.site` подтверждён, отправка писем авторизации включена.
- Последнее письмо на `chefcook2228@gmail.com` было принято почтовой системой со статусом `sent`; адрес не заблокирован.
- Этот Gmail уже зарегистрирован и подтверждён. Повторная регистрация на тот же адрес не создаёт новый аккаунт и не должна отправлять новый код.
- Сейчас форма не распознаёт этот случай и всё равно открывает экран ввода кода. Поэтому выглядит так, будто письмо потерялось.

## Что исправим

1. После регистрации проверять, был ли действительно создан новый неподтверждённый аккаунт.
2. Если почта уже зарегистрирована, не открывать экран ожидания кода, а показать понятное сообщение «Эта почта уже используется — войдите или восстановите пароль».
3. Добавить это сообщение на русском, казахском и английском языках.
4. Для нового адреса сохранить текущий выбор подтверждения: код по email или SMS.
5. Проверить сценарии:
   - новая почта получает код и может его подтвердить;
   - занятая почта получает понятную ошибку;
   - повторная отправка кода работает только для нового неподтверждённого аккаунта.

## Технические детали

- Исправить обработку результата регистрации в форме и функции авторизации.
- Не раскрывать постороннему пользователю лишние данные об аккаунте сверх безопасного сообщения и доступных действий.
- После изменений проверить фактический статус отправки в журнале писем и работу формы в браузере.
